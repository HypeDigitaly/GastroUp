# Build Pipeline

> **Architecture update (2026-06-04):** Pages are no longer single root HTML files.
> All 4 pages (`index`, `obchodni-podminky`, `ochrana-osobnich-udaju`, `404`) are
> **assembled from modular partials in `src/`** by `scripts/assemble.js`
> (`<!-- @include … -->` directives + `{{param}}` substitution), then minified.
> See [src/README.md](../src/README.md). References to "index.html in repo root"
> below describe the assembled equivalent.

## Overview

The GastroUp build pipeline is a Node.js-based system (`build.js`) that optimizes the static marketing site for production deployment. It automates page assembly from `src/` partials, HTML minification, image format conversion (WebP/AVIF), and curated file copying to the `dist/` directory.

**Run the build:**
```bash
npm run build
```

## Build Steps

### 1. Page Assembly + HTML Minification

The build assembles each page in `build.js` `PAGES` from `src/pages/*.html` (resolving includes recursively, failing the build on any unresolved directive, missing `{{param}}`, or missing critical block — cookie banner / GA snippet / `</html>`), then minifies using `html-minifier-terser` with aggressive settings:

- **Collapse whitespace**: removes unnecessary whitespace
- **Remove comments**: strips HTML comments
- **Minify JS**: compresses inline scripts
- **Minify CSS**: compresses inline styles
- **Remove redundant attributes**: eliminates unnecessary HTML attributes

**Result:** ~22% size reduction (typical: 40KB → 31KB)

The minified HTML is output to `dist/index.html`.

**Verification:**
```bash
npm run build
# Look for: "Minified: X bytes (saved Y bytes, Z%)"
```

### 2. Image Processing with Sharp

The build converts two source PNG images to multiple formats using the `sharp` library for optimal delivery:

#### Source Images
- `Logo_GastroUp_2_transparent.png` (nav/footer logo, ~288KB)
- `Zakladatel_Jakub_Hnat.png` (founder photo, ~402KB)

#### Output Formats
For each source image, the build generates:
- **Original PNG** (copied as-is)
- **WebP** (quality 82) — modern browsers, ~88% smaller
- **AVIF** (quality 55) — next-generation format, ~94% smaller

**Typical compression:**
```
Logo_GastroUp_2_transparent.png:
  ✓ Copied original PNG: 288,000 bytes
  ✓ Generated WebP: 34,000 bytes (saved 254,000 bytes)
  ✓ Generated AVIF: 18,000 bytes (saved 270,000 bytes)

Zakladatel_Jakub_Hnat.png:
  ✓ Copied original PNG: 402,000 bytes
  ✓ Generated WebP: 20,000 bytes (saved 382,000 bytes)
  ✓ Generated AVIF: 13,000 bytes (saved 389,000 bytes)
```

These images are referenced in `index.html` via `<picture>` elements with fallback chains:
```html
<picture>
  <source srcset="/path/image.avif" type="image/avif" />
  <source srcset="/path/image.webp" type="image/webp" />
  <img src="/path/image.png" alt="..." />
</picture>
```

**Cache strategy:** Images use "rename-on-change" policy (immutable cache headers in netlify.toml) — when updated, rename the file so new content is always fresh.

### 3. Curated File Copying

The build copies only essential files to `dist/`, excluding development artifacts:

#### Files Copied
- `og-image.png` — Open Graph preview image (1200×630)
- `favicon.ico` — Browser favicon
- `favicon-192.png` — Android home screen icon
- `favicon-512.png` — Android splash screen
- `apple-touch-icon.png` — iOS home screen icon
- `robots.txt` — Search engine crawling directives
- `sitemap.xml` — SEO site structure map
- `llms.txt` — Machine learning model instructions
- `site.webmanifest` — PWA manifest
- `404.html` — Custom error page (branded Czech)
- `fonts/` directory (if present)

#### Directories Excluded
- `napady-fotografie.html`
- `Logo-Design/`
- `Assets/`
- `brand-assets/`
- `Kampaně/`
- `Website-Copy/`
- `node_modules/`
- `docs/`

**Warning handling:** If a required file is missing (e.g., generated by a parallel task), the build logs a warning but continues:
```
⚠️  WARNING: The following files were not found in source (may be generated by parallel tasks):
   - og-image.png
```

## Integration with Netlify

**netlify.toml** configuration:
```toml
[build]
  publish = "dist"           # Netlify serves from dist/
  command = "npm run build"  # Build command
```

When you push to the main branch, Netlify automatically:
1. Runs `npm run build`
2. Uploads `dist/` contents to the CDN
3. Serves from immutable cache (images) or revalidate (HTML)

## Scripts

Add `build` to your Node environment:

**package.json:**
```json
{
  "scripts": {
    "build": "node build.js",
    "dev": "netlify dev",
    "type-check": "tsc --noEmit"
  }
}
```

## Development Notes

### File Naming & Diacritics

Asset filenames must use ASCII characters (no diacritics). All diacritics have been replaced with ASCII equivalents:
- ✓ `Zakladatel_Jakub_Hnat.png` (correct)
- ✗ `Zakladatel_Jakub_Hnát.png` (avoid)

This ensures compatibility across different file systems and HTTP headers.

### Fonts Directory

The `fonts/` directory is copied as-is. Currently, this directory is optional and contains only a README. For font self-hosting setup instructions, see `fonts/README.md`.

**Current state:** Fonts remain Google-hosted (non-blocking load via preload + onload swap). Self-hosting is a deferred optimization.

## Troubleshooting

### Build Fails with "Required image not found"
Verify that source images exist in the repository root:
```bash
ls -la Logo_GastroUp_2_transparent.png
ls -la Zakladatel_Jakub_Hnat.png
```

### dist/ Directory Not Created
Check Node.js version:
```bash
node --version  # Should be 18+ or 20 (as per netlify.toml NODE_VERSION)
```

### Image Files Not Optimized
Verify `sharp` is installed:
```bash
npm install
```

Sharp requires system libraries (libvips). On Linux, install:
```bash
# Ubuntu/Debian
apt-get install libvips

# macOS
brew install vips
```

On Windows, binaries are included with npm package.
