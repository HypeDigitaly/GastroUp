# Self-Hosted Fonts for GastroUp

This directory should contain subsetted font files (WOFF2) for optimal performance.

## Font Requirements

The site uses three variable font families:

1. **Fraunces** (display font)
   - Variable axes: opsz 36..144, wght 300..600, SOFT 0..100, WONK 0..1, ital 0/1
   - Used for: headings, display text

2. **Geist** (sans-serif, body font)
   - Variable axis: wght 300..900
   - Used for: body text, UI elements

3. **Geist Mono** (monospace font)
   - Weights: 400, 500, 600
   - Used for: code blocks, technical text

## Generation Instructions

### Option A: Using fonttools (Python)

```bash
pip install fonttools brotli

# Download fonts from Google Fonts
# Fraunces
curl -o fraunces.ttf "https://fonts.gstatic.com/s/fraunces/v32/8Au-p_xrzhyG8_nX4RjVelEI3EoqvB5LtrC98FKP8e5XsHIJA3clWwxlKQTILDGD2Wx3YVZLpGBKc.0.ttf"

# Geist
curl -o geist.ttf "https://cdn.jsdelivr.net/npm/@fontsource/geist/files/geist-latin-400-normal.ttf"

# Geist Mono
curl -o geist-mono.ttf "https://cdn.jsdelivr.net/npm/@fontsource/geist-mono/files/geist-mono-latin-400-normal.ttf"

# Subset for Czech (Latin + Latin Extended-A for ě š č ř ž ý á í é ú ů ó ť ď ň)
pyftsubset fraunces.ttf --unicodes="U+0000-U+00FF,U+0100-U+017F" --flavor=woff2 --output-file=fraunces-subset.woff2

pyftsubset geist.ttf --unicodes="U+0000-U+00FF,U+0100-U+017F" --flavor=woff2 --output-file=geist-subset.woff2

pyftsubset geist-mono.ttf --unicodes="U+0000-U+00FF,U+0100-U+017F" --flavor=woff2 --output-file=geist-mono-subset.woff2
```

### Option B: Using subset-font (Node.js)

```bash
npm install subset-font

# Create a Node.js script to subset fonts
node -e "
const subsetFont = require('subset-font');
const fs = require('fs');

// Czech glyph ranges: Latin (U+0000-U+00FF) + Latin Extended-A (U+0100-U+017F)
const unicodes = Array.from({length: 384}, (_, i) => i).map(i => String.fromCharCode(i));

// Fraunces from Google Fonts
fetch('https://fonts.gstatic.com/s/fraunces/v32/8Au-p_xrzhyG8_nX4RjVelEI3EoqvB5LtrC98FKP8e5XsHIJA3clWwxlKQTILDGD2Wx3YVZLpGBKc.0.ttf')
  .then(res => res.arrayBuffer())
  .then(async buf => {
    const subset = await subsetFont(Buffer.from(buf), unicodes.join(''), { targetFormat: 'woff2' });
    fs.writeFileSync('fraunces-subset.woff2', subset);
  });
"
```

## Expected Files

Once generated, this directory should contain:

- `fraunces-subset.woff2` (~40-50 KB)
- `geist-subset.woff2` (~60-80 KB)
- `geist-mono-subset.woff2` (~45-60 KB)
- `font-face.css` (generated by build pipeline)

## CSS Integration

After generation, the build pipeline creates `font-face.css` with appropriate @font-face declarations and metric overrides for system fallbacks.

Include it in your HTML like:

```html
<link rel="stylesheet" href="/fonts/font-face.css" />
```

## Fallback

If subsetted fonts are not generated, the site will use Google Fonts CDN as a fallback (see `index.html` line 11). Self-hosting is a performance optimization, not a requirement.
